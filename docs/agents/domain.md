# Domain Docs

This repository uses a **single-context** domain layout.

## Sources of Truth

- Domain language: `CONTEXT.md` at repository root
- Architectural decisions (ADRs): `docs/adr/`

## Consumer Rules for Skills

1. Read `CONTEXT.md` first to align terminology and concepts.
2. Read `docs/adr/` before proposing architecture changes.
3. If no ADR exists for a decision area, proceed and document new decisions there.
4. Keep domain terms consistent with `CONTEXT.md` in code reviews and proposals.
